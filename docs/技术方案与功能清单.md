# TeamChron 技术方案与功能清单

统领工时管理平台 · 基于当前仓库代码整理 · 面向研发团队的轻量工时与项目协作

**标签：** Monorepo · Spring Boot + Vue3 · RBAC · Docker 生产部署  
**整理日期：** 2026-11-11  
**来源：** controller / router / deployment 与现网实现

| 指标 | 数量 |
|------|------|
| 已上线功能项 | 32 |
| 后端 Controller | 16 |
| 核心 API 模块 | 13+ |
| 生产容器服务 | 3（MySQL + Backend + Frontend） |

## 定位

解决研发团队工时难统计、进度不透明、工具过重等问题；聚焦项目 / 任务 / 工时 / 权限，支持自托管与 Docker 一键部署。

## 一、技术方案

### 1.1 技术栈

| 层级 | 选型 |
|------|------|
| 前端 | Vue 3.4 · TypeScript 5.3 · Vite 5 · Element Plus · Pinia · Vue Router · Axios · ECharts · dhtmlx-gantt |
| 后端 | Java 8 · Spring Boot 2.7 · MyBatis-Plus · JWT · SpringDoc OpenAPI · PageHelper · Flyway |
| 数据 | MySQL 8.0 · utf8mb4 · 软删除与审计字段 |
| 部署 | Docker Compose · Nginx 同域反代 · MySQL + Backend + Frontend · 端口 80/8080 |

### 1.2 逻辑架构

| 分层 | 职责 |
|------|------|
| Controller | HTTP、参数校验、统一 Result 响应 |
| DTO / Converter | CreateReq / UpdateReq / InfoResp / QueryReq 与 Entity 转换 |
| Service | 业务逻辑、事务、权限校验（AuthService） |
| Mapper / Model | MyBatis XML、Entity、Enums、ErrorCode |
| Infra | JWT 拦截、CORS、全局异常、UserContext、工具类 |

标准三层 + DTO；领域目录为 `model/`（非 `domain/`）。认证无状态 JWT；业务权限通过 AuthService 做项目/任务可见性校验。

### 1.3 认证与安全

**认证链路**

1. 验证码下发 cid + 图片 + RSA 公钥  
2. 前端加密密码 → 后端解密再 BCrypt  
3. 签发 JWT，后续请求 `Authorization: Bearer`

**授权模型**

- 角色 → 权限 → 菜单/按钮  
- 路由守卫 + 按钮权限码  
- 数据级：项目成员、全局查看等  

### 1.4 部署架构

| 项 | 说明 |
|----|------|
| 形态 | Docker Compose：MySQL + Backend + Frontend(Nginx) |
| 访问 | 浏览器只访问 80；`/api` 反代到 `backend:8080` |
| 配置 | `.env.prod`（密码、JWT、CORS）；勿入库 |
| 库变更 | Flyway 版本脚本；空库会按版本号全量执行 |
| 注意 | Alpine 验证码需字体/libgcc；生产日志建议打控制台便于排障 |

相关文件：`docker-compose.prod.yml`、`deployment/README.md`、`.env.prod.example`。

### 1.5 关键模块

| 前缀 | 范围 |
|------|------|
| `/api/captcha` | 验证码 + RSA 公钥 |
| `/api/users` | 登录注册、用户、角色绑定、改密重置 |
| `/api/auth` | 当前用户权限/角色 |
| `/api/projects` | 项目、成员、公告 |
| `/api/iterations` | 迭代 |
| `/api/tasks` | 任务检索、状态、子任务、看板表 |
| `/api/work-hours` | 工时查询与批量填报 |
| `/api/leave-types` | 请假类型 |
| `/api/statistics` | 看板与多维统计 |
| `/api/gantt` | 甘特数据与依赖 |
| `/api/roles` `/permissions` `/menus` | RBAC 配置 |
| `/api/departments` | 部门 |
| `/api/operation-logs` | 操作日志 |
